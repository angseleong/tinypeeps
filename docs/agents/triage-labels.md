# Triage labels

The skills speak in terms of five triage roles. This file maps those roles to the label strings used in this repo's issue tracker.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AI agent |
| `ready-for-human` | `ready-for-human` | Needs a person, such as anything judged by looking at the office or by a real Claude plan |
| `wontfix` | `wontfix` | Will not be actioned |
